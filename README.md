# Smart-Hospital-System



\# Smart Hospital \& Resource Allocation System



A C programming project designed to manage daily hospital operations, patient records and bed allocations.



\## Descriptions

This is a menu driven system built using C language. It handles patient registration, emergency urgency levels, bed allocations and billing calculations.



\## Features

* Patient registration with urgency levels(level 1, level 2, level 3)
* Real time bed occupancy tracking in wards
* Automatic billing calculation with emergency surcharges and age discounts
* Patient queue management based on urgency
* Daily hospital analytics and report generation



\## Data Structures Used

* \*\*Multiple 1D Arrays:\*\* Used to store patient information like IDs, Names, Ages and urgency levels.
* \*\*2D Arrays(Matrix):\*\* Used to track bed availability across different wards.



\## Requirements \& Setups

* Built using standard c language
* Cand be compiled and run using Code::Blocks or any standard C compiler



\## How to Run

1. Open 'main.c' in Code::Blocks.
2. Build and Run
